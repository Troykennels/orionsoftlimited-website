# Orion Soft Website — Setup, Edit & Deploy Guide

## Public Launch Status

The current project is a ready-to-build Vite/React website. It now includes:

- Responsive layouts for phone, tablet, laptop, and desktop screens.
- Public product, systems, services, pricing, about, FAQ, feedback, privacy, and terms pages.
- SEO metadata, favicon, web manifest, robots file, and social preview image.
- Working lead/feedback forms with an email fallback and optional form endpoint.
- Production build output generated by `npm run build`.

Before going live, replace only the business-specific values you have not supplied yet:

- `COMPANY_RC` in `src/App.jsx`, if you want the CAC/RC number shown publicly.
- `VITE_ORIONSOFT_FORM_ENDPOINT` in your host environment, if you want forms delivered to a backend instead of opening email.

## What You Have

The active website is in `src/App.jsx` and runs as a React app through Vite. The older `orionsoft_website.jsx` file is kept as a standalone source copy.

This guide assumes you have zero coding setup experience. Follow it step by step.

## Step 1: Install the Tools (One-Time Setup)

You need two things on your computer:

### A) Install Node.js
1. Go to https://nodejs.org
2. Download the **LTS** version (the green button)
3. Run the installer, click "Next" through everything
4. To verify it worked, open **Command Prompt** (Windows) or **Terminal** (Mac) and type:
   ```
   node --version
   ```
   You should see something like `v20.x.x`

### B) Install a Code Editor
1. Go to https://code.visualstudio.com
2. Download and install **Visual Studio Code** (VS Code)
3. This is where you will edit your website

---

## Step 2: Create the Project

Open your **Terminal** (Mac) or **Command Prompt** (Windows) and run these commands one at a time:

```bash
# Create a new React project using Vite (fast, modern, free)
npm create vite@latest orionsoft-website -- --template react

# Go into the project folder
cd orionsoft-website

# Install dependencies
npm install
```

Now open this folder in VS Code:
```bash
code .
```

## Step 5: Edit Your Website

### Where to Change Your Details

Open `src/App.jsx` in VS Code and update the constants near the top if needed:

```jsx
const COMPANY_EMAIL = "orionsoftlimited@gmail.com";
const COMPANY_PHONE = "08165556805";
const FOUNDER_NAME = "Famojuro Mathew";
const COMPANY_RC = "9535128";
```

The live site already uses these values. Change `COMPANY_RC` only if the registration number changes in future.

### How to Change Pricing
Search for `₦350K` or `₦500K` in the file — you will find the pricing section. Edit the amounts directly.

### How to Change Colors
At the top of the file, you will find a `COLORS` object (around line 10). The main colors are:
- `accent: "#00C8FF"` — the blue highlight color
- `mint: "#34D399"` — the green accent
- `bg: "#050A12"` — the dark background

Change any hex color to customize the look.

### How to Add/Remove Services
Search for `const services =` — you will find the services list with icons, titles, descriptions, and prices. Add or remove items from this array.

### How to Add New Systems or Apps
Search for `const systems =` in `src/App.jsx`. Add a new item to that list with:
- `name` — the product or app name
- `status` — Available, In development, Planned, or On request
- `audience` — who the system is for
- `desc` — what it does
- `features` — short feature labels

The website will automatically show it in the **Systems & Apps** section.

### How to Receive Requests, Reports, and Feedback

Recommended setup for this project now:

- Built-in Vercel endpoint: deploy `api/forms.js` together with the site and add `RESEND_API_KEY`, `FORM_TO_EMAIL`, and `FORM_FROM_EMAIL` in Vercel environment variables. `FORM_FROM_EMAIL` must use a domain verified in Resend, for example `Orion Soft Website <hello@orionsoftlimited.com>`.
- External endpoint override: set `VITE_ORIONSOFT_FORM_ENDPOINT` only if you want to use another service instead of the built-in endpoint.
- Email fallback: if neither endpoint works, the site still opens the visitor's email app addressed to `orionsoftlimited@gmail.com`.

The Get Started form and Feedback page can send submissions in two ways:

1. **Direct form endpoint**: create a form endpoint using a service like Formspree, Getform, Basin, Make, Zapier, or your own API. Then add this environment variable before deploying:
   ```
   VITE_ORIONSOFT_FORM_ENDPOINT=https://your-form-endpoint.example
   ```
   On Vercel, add it under **Project → Settings → Environment Variables**.

2. **Email fallback**: if no endpoint is configured, the website opens the visitor's email app and prepares a message to `orionsoftlimited@gmail.com`. To change that email, edit `COMPANY_EMAIL` near the top of `src/App.jsx`.

## Step 6: Deploy to the Internet (Make It Live)

### Option A: Vercel (Recommended — Easiest)

1. Go to https://vercel.com and sign up (free) using your email or GitHub
2. Install the Vercel CLI:
   ```bash
   npm install -g vercel
   ```
3. In your terminal, inside your project folder:
   ```bash
   vercel
   ```
4. Follow the prompts:
   - "Set up and deploy?" → Yes
   - "Which scope?" → Select your account
   - "Link to existing project?" → No
   - "Project name?" → orionsoft-website
   - "Directory?" → ./
   - "Override settings?" → No
5. Wait 60 seconds. Vercel gives you a live URL like:
   ```
   https://orionsoft-website.vercel.app
   ```
6. Your website is now LIVE on the internet!

### Option B: Netlify (Also Free & Easy)

1. Go to https://netlify.com and sign up
2. First, build your project:
   ```bash
   npm run build
   ```
   This creates a `dist` folder with your production-ready website.
3. Drag and drop the entire `dist` folder onto the Netlify dashboard
4. Your site is live at something like `https://random-name.netlify.app`

## Step 7: Connect a Custom Domain

A `.vercel.app` URL works but looks unprofessional. You want something like `orionsoft.com.ng` or `orionsoft.ng`.

### Buy a Domain
Nigerian domain options:
- **Whogohost** (whogohost.com) — `.com.ng` domains from ~₦2,500/year
- **Qservers** (qservers.net) — `.ng` and `.com.ng` domains
- **Namecheap** (namecheap.com) — `.com` domains from ~$9/year

Suggested domains to check:
- `orionsoft.com.ng`
- `orionsoft.ng`
- `orionsoftware.com`
- `carecore.com.ng`

### Connect Domain to Vercel
1. In your Vercel dashboard, go to your project → Settings → Domains
2. Click "Add Domain" and type your domain (e.g. `orionsoft.com.ng`)
3. Vercel shows you DNS records to add. Go to your domain registrar (Whogohost, etc.)
4. Add the DNS records Vercel gives you (usually an A record or CNAME)
5. Wait 10-30 minutes for DNS to propagate
6. Your website is now live at your custom domain with free HTTPS!

### Connect Domain to Netlify
1. In Netlify dashboard → Domain Settings → Add custom domain
2. Follow the same DNS process as above
